# LabDOE 2.0

Aplicativo estático para planejamento de experimentos (DOE), regressão, diagnósticos, superfícies de resposta e otimização experimental.

## Publicação no GitHub Pages

1. Crie um repositório público denominado `LabDOE`.
2. Envie `index.html`, `.nojekyll` e `README.md` para a raiz da branch `main`.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, `main` e `/(root)`, e salve.
4. Acesse `https://SEU-USUARIO.github.io/LabDOE/`.

## Observações

- O site funciona inteiramente no navegador, sem serviços externos.
- Verifique modelos, suposições, intervalos e condições ótimas com análises independentes e ensaios de confirmação antes de uso industrial.
- O GitHub Pages oferece acesso público ao conteúdo e ao código; não carregue dados industriais confidenciais no repositório.
- O aplicativo não constitui sistema validado para ambiente regulado.
